# UTM Keeper

A WordPress plugin in preparation. See [the concept](docs/CONCEPT.md) and [approved MVP plan](docs/MVP-PLAN.md).

**Current status:** scaffold only. The plugin starts disabled. There is no settings screen, campaign capture, browser storage, or link forwarding yet. Do not deploy it expecting attribution to work.

## Development checks

From this directory, run `npm test` for dependency-free JavaScript checks and `php -l utmkeeperflow.php` for PHP syntax. Activate in a local WordPress installation to check the plugin bootstrap. The complete implementation is tracked in [the MVP GitHub issue](https://github.com/gasatrya/utmkeeperflow/issues/1).
